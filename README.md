## 🛰️ Currently working on

### [Spacecraft Knowledge Graph](https://github.com/btinic/spacecraft-knowledge-graph)

An independent project exploring **knowledge-graph-based spacecraft systems engineering**.

The objective is to integrate engineering information from different tools into a common semantic knowledge graph.

**First use case: CAD → RDF → SPARQL**

- Model a spacecraft mounting bracket in AutoCAD.
- Extract mechanical properties, including volume, centroid, and moments of inertia.
- Convert the engineering data into RDF using Python.
- Retrieve and analyze the information using SPARQL.

**Next:** Integrating CubeSat electrical power budgets, with longer-term applications in functional dependencies, failure propagation, and model-based FMEA.

Because apparently engineering subsystems weren't complicated enough until I decided to make their data talk to each other.
